# WEBTECH-Projekt Julius Weckowski, Kenny Spannuth bei Taherkhani

- Gym/Cardio/Isometric-Hold Tracker. Man soll jeden Tag tracken können wo man trainiert hat oder auch nicht. Jeweils mit den Kraftübungen, Satzanzahl, Wiederholungen und Gewicht.


- TechStack
-   Backend: Java + Spring Boot 
-   Frontend: TypeScript + Vue.js
-   Datenbank: Managed PostgreSQL

- Entity Klassen:
-   appUser, exercise, exerciseType, traininigDay, exercisEntry, exerciseSet
